# 任务 T6：新建 js/diary.js——今日日记编辑器（自包含 ES module）

写一个全新的浏览器 ES module（无依赖、无框架）。它不接触任何其他文件的内部，只依赖注入的接口。

## 导出契约（严格）
```js
export function openDiary({ get, put, toast, dateStr })
```
- get(path) → Promise<{text, sha}>；put(path, text, message) → Promise<{unchanged}>（这些由宿主注入）
- 调用后在 document.body 末尾创建全屏编辑层（div.overlay.diary.on），完成后移除
- 层内：顶栏（← 返回按钮 .diary-close、标题「日记 · <dateStr>」）、一个 textarea、底部「保存」按钮(.primary)

## 文件与模板
- 目标文件路径：`日记/<dateStr>.md`（dateStr 如 2026-09-12）
- 打开时 get 该文件：不存在 → 用模板初始化：
  `## <dateStr> 周<X>\n\n**做了什么**\n- \n\n**感受**\n- \n`
  （周X 由 dateStr 算，X∈日一二三四五六）
- 存在 → textarea 预填全文
- 保存：put(path, textarea.value, 'app: 日记')，成功后 toast('已保存') 并关闭层；失败 toast 错误（true）

## 样式类（CSS 已存在，只用这些类）
.overlay .on .filebar .primary .mini —— 层结构：
<div class="overlay diary on"><div class="filebar"><button class="diary-close">←</button><strong>日记 · dateStr</strong></div><textarea class="diary-text"></textarea><button class="primary diary-save">保存</button></div>
textarea 样式类 .diary-text：占满宽度、min-height 50vh（在 :root 变量体系下写一小段 <style> 注入是允许的，仅限 .diary-text/.diary 相关选择器）

## 硬性规则
- 零依赖；不修改其他文件；不使用 innerHTML 插入未转义用户内容
- 全部代码放进一个 js/diary.js；直接输出完整文件内容
