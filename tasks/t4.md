## 设计规格（严格遵守）

亮色为主模式，`@media (prefers-color-scheme: dark)` 提供深灰辅模式。全部颜色用 CSS variables。

```
亮：--bg #ffffff; --surface #f5f5f7; --surface-2 #ebebf0; --surface-3 #e3e3e8
    --fg #1d1d1f; --fg-strong #000; --dim #86868b; --faint #aeaeb2
    --line rgba(0,0,0,.06); --line-strong rgba(0,0,0,.12)
暗：--bg #1c1c1e; --surface #242426; --surface-2 #2c2c2e; --surface-3 #3a3a3c
    --fg #e5e5e7; --fg-strong #fff; --dim #98989f; --faint #636368
    --line rgba(255,255,255,.08); --line-strong rgba(255,255,255,.16)
共通：--acc #3478f6; --acc-dim rgba(52,120,246,.10); --ok #34c759; --bad #ff3b30; --warn #ff9500
--r 10px; --r-lg 14px; 间距 4/8/12/16/24/32; 字号 12/13/15/17/22
```
